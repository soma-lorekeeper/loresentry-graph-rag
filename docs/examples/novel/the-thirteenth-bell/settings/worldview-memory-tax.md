# 기억세와 기억 반환

해무시에서는 시민이 일 년에 한 번 기억 하나를 시에 납부하는 기억세를 시행했다. 기억이 물로 빠져나가려면 사람이 손을 담근 채 같은 일을 떠올리는 과정이 필요하다. 납부한 기억은 물에 담겨 지하 수문을 움직이는 힘이 된다. 이미 등록된 기억은 중복 납부할 수 없다.

대홍수 때의 북문 긴급 폐쇄에는 강한 기억이 한꺼번에 필요했다. 긴급 사용이 끝나면 남은 기억을 납부자에게 반환한다는 조건이 있었다. 직접 납부한 기억과 동의 없이 딸려간 가족 기억은 구분해야 하며, 원장의 번호와 당사자의 확인 없이 기억수에 손을 담그면 타인의 기억을 가져갈 위험이 있다. 이미 사용되어 소진된 기억은 반환할 수 없다.

5화 말의 임시 회의에서 기억세 징수를 중지했다. 완전한 폐지는 설비 교체 비용과 교대 인력을 마련한 뒤 다시 결정하기로 했다. 징수 중지를 완전한 폐지로 바꾸어 기록하지 않는다. 기존 기억의 반환과 동의 없는 수집의 책임은 별도 조사 대상이다.
