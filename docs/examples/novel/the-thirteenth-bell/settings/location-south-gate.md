# 해무시의 수문과 반환수로

해무시는 바다보다 낮은 분지에 있다. 강물이 불어나면 북문을 닫고 남문을 열어 물을 빼야 한다. 두 문은 수압과 축의 움직임이 서로 영향을 주며, 한쪽을 급히 닫으면 반대쪽 축에 무게가 몰린다. 기억수 부족만으로 모든 고장을 설명할 수 없고 쇠의 마모와 축의 어긋남도 확인해야 한다.

대홍수 이후 폐쇄된 남쪽 역의 지하 승강장은 기억수 저장고로 바뀌었다. 지도에서 지워진 반환수로가 남쪽 역에서 북문 아래 조정실까지 이어진다. 서하는 새 지도에 반환수로를 복원하고 주민 통행 구간과 작업자 전용 구간을 구분했다.

5화 말에 새 교대조가 양쪽 수문의 인계를 마쳤다. 평소 열두 번의 종 뒤에 울리는 열세 번째 종은 지상의 교대 인계가 끝났다는 신호다.
