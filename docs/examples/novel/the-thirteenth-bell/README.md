# 열세 번째 종

기억을 세금으로 내는 항구도시 해무시를 배경으로 한 판타지 미스터리다.
1~5화에서 윤서하와 백도윤이 기억세와 수문의 비밀을 추적하는 사건을 마무리하고,
6화에서 기억 반환소의 방문 전달과 항만의 새로운 단서를 다룬다.
문서·관계 제안 테스트를 위해 새로 작성한 가상 소설이다.

## 수정과 fake 입력 연결

5화의 도윤 의지 덮개 재질을 **황동 → 검게 산화시킨 강철**로 수정했다.
[수정 전 5화](baseline/05-the-new-map.rev1.md)는 비교용으로 보존했다.
6화에서는 도윤이 민해주가 맡은 기억 반환소의 방문 전달 담당이 된다.
도윤의 조합 소속과 오후 배달 업무는 유지한다.

[fake S3 입력](../../refresh/novel/input.json)에는 수정한 5화(`chapter-05`, revision 2)와
새 6화(`chapter-06`, revision 1)의 본문 전체·분류·현재 명시 관계만 담았다.
1~4화와 수정 전 5화는 이번 변경 목록에 넣지 않는다. revision은 테스트 시나리오에서
지정한 값이며 이 코드가 Content 문서의 revision을 올리는 것은 아니다.

[실행 안내](../../refresh/novel/README.md)에서 기존 설정 fake와 재생 응답, 결과 확인 방법을 본다.
